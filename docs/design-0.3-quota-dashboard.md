# UI 重构设计 — 配额仪表盘（方案 B）

> v0.2.1 → v0.3.0 · 用户已通过交互式 HTML mockup 选定本方案

## 目标布局

```
┌──────────────────────────┐
│ ▼ 14:23       ████████░░ │  ← 箭头=折叠 | 时间=三态 | 电量条+%
│ ──────────────────────── │
│ DeepSeek        ¥12.34 ✓ │  ← 点击行=手动刷新, spinner, 完成✓闪
│ 智谱    45% ▓▓▓░░ 2h13m  │  ← usage 条 + 动态倒计时
│ MiniMax  92% ▓▓▓▓▓ 18m ⚠ │  ← usage≥90% 呼吸告警
│ Kimi         失败·点击重试 │  ← 错误态可点恢复
└──────────────────────────┘
```

## 交互规格

| 交互 | 触发 | 反馈 |
|------|------|------|
| 面板折叠 | 点击首行箭头 | 全面板收起为一行（沿用 kv 持久化） |
| 时间三态 | 点击时间 | HH:mm → HH:mm:ss → 周 M/D |
| 行级手动刷新 | 点击余额行 | braille spinner(80ms/帧) → 成功"✓"前缀 600ms |
| 错误重试 | 点击错误行 | 同上，成功恢复数值/维持失败 |
| 告急呼吸 | 自动 usage≥90% | error 色↔40%alpha 双态 600ms 切换 |

## 数据协议（向后兼容）

extractor 返回 string 不变；新增可选结构化返回：

```ts
{ text: string, usage?: number /*0-1*/, resetIn?: number /*ms*/ }
```

- `usage` → 渲染 5 格迷你条 `▓▓▓░░`
- `resetIn` → 以查询时刻为基准的动态倒计时（每 5s 随时钟修正）
